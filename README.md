# DSiMusic

Open-source album-oriented music player for Nintendo DSi.

Target: Nintendo DSi XL
Platform: BlocksDS / libnds
Audio: WAV PCM 16-bit
Development OS: Void Linux
Testing: melonDS (DSi mode)
Launch: TWiLight Menu++ without Unlaunch

## Development Transparency

**This project is entirely vibe-coded.**

The code for this project is written with the help of AI,
rather than being manually programmed by me.

I wanted a proper album-based music player for my Nintendo
DSi XL, but couldn't find one that met my needs.

I don't have a personal interest in learning an entire
programming language and Nintendo DS development environment
just to create this one application.

Instead, I'm attempting to build it through vibe coding.

My role is to define features, make design decisions,
test the software, report issues, and guide development.
The implementation is AI-generated.

I'm not claiming to have personally written the code.

The goal is to create a useful, free and open-source
music player for the Nintendo DSi.

AI-generated code may contain bugs and should not be
considered reliable without testing.
